# SIKE FORENSICS

AI media forensics platform for image, video and audio analysis, provenance, metadata inspection, evidence scoring, forensic reports and remediation workflows.

> Original implementation. Third-party projects are used as architectural inspiration unless their licenses explicitly permit reuse.

## Status

Phase 1 foundation: upload/analyze API, metadata and hash inspection, image ELA, audio spectral features, video frame sampling, evidence fusion, JSON/HTML reports, metadata cleaning, and removal-request drafting.

See `docs/SETUP.md` to run locally.

Results are probabilistic forensic indicators, not proof of authenticity or manipulation. Preserve originals and review evidence before taking action.
